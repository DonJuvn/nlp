# Веб-приложение: определение кодекса РК по тексту статьи (неделя 5)

## Что делает приложение

Пользователь вставляет текст статьи (при желании добавляет её заголовок) и нажимает «Анализировать». Дообученная модель BERT предсказывает, из какого кодекса Республики Казахстан взята статья. Классов 7: Трудовой, Уголовный, Гражданский (обе части вместе), Земельный, Экологический, Кодекс об административных правонарушениях, Кодекс о браке (супружестве) и семье.

## Элементы интерфейса

- **Поле ввода текста** и необязательное поле заголовка (при обучении модель видела «заголовок + текст», поэтому заголовок немного повышает точность).
- **Кнопка «Анализировать».**
- **Результат:** предсказанный кодекс, уверенность модели в процентах и полоса уверенности.
- **Визуализация:** горизонтальная диаграмма и таблица вероятностей по всем 7 кодексам.
- **Предупреждения:** если уверенность ниже 60 % (вероятно, общая норма, которая встречается в нескольких кодексах), и если текст длиннее лимита модели и был обрезан.
- **История запросов** за сеанс с возможностью скачать её в CSV.
- **Боковая панель:** выбор языка интерфейса (русский / казахский), 7 контрольных текстов одним щелчком, сведения о модели (папка, устройство, максимальная длина текста).

## Запуск

Из корня проекта, где лежит папка `models/`:

```
pip install streamlit
streamlit run app.py
```

Браузер откроет http://localhost:8501. Приложение само находит модель: сначала `models/bert_best` (лучшая модель 4-й недели), затем `models/bert_legal_cls` (3-й недели). Другую папку можно указать переменной окружения `MODEL_DIR`.

## Файлы

- `app.py` — интерфейс на Streamlit.
- `predictor.py` — загрузка модели и предсказание (работает без интерфейса).
- `control_texts.py` — 7 новых контрольных текстов (по одному на класс) и казахские названия кодексов.
- `run_control_tests.py` — прогон контрольных текстов без интерфейса, результат в `report/week5_control_tests.csv`.
- `requirements_app.txt` — зависимости.

## Тестирование на 5 новых текстах

1. Запустите приложение.
2. В боковой панели выберите «Пример 1», нажмите «Анализировать» и сделайте скриншот (Win+Shift+S). Сохраните как `screenshots/test1.png`. Повторите для примеров 2–5 (при желании и 6–7).
3. Для таблицы в отчёт выполните `python run_control_tests.py`: он выведет для каждого текста ожидаемый и предсказанный кодекс.

Контрольные тексты написаны специально и не взяты из корпуса, поэтому проверяют модель на материале, которого она не видела.

## Ограничения

- Модель различает только эти 7 кодексов: для статьи из другого закона она всё равно выберет один из них, поэтому низкая уверенность — сигнал сомневаться.
- Текст длиннее лимита обучения (обычно 256 токенов) обрезается: учитывается только его начало.
- Очень короткие и общие нормы («основные понятия», «сфера применения») часто встречаются в нескольких кодексах, и модель на них ошибается чаще всего (см. анализ ошибок недели 4).
